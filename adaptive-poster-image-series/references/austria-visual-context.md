# Austria Visual Context

## Grundsatz

Oesterreich sichtbar machen, wenn es inhaltlich hilft. Nicht als dekoratives Branding verwenden.

## Prioritaet

1. reale oder glaubwuerdige mitteleuropaeische Umgebung
2. oesterreichische Infrastruktur oder Architektur, wenn sachlich passend
3. typische Materialien, Oeffi-, Verwaltungs- oder Stadtkontexte ohne erfundene Beschriftung
4. Nationalsymbolik nur bei echter inhaltlicher Relevanz

## Verbot ohne Anlass

- Bundeswappen oder Adler
- Amtssiegel
- Parteizeichen
- rot-weiss-rote Banderole auf mehreren Motiven
- Flagge als Ersatz fuer fehlende Bildidee

## Faktenintegritaet

Keine erfundene Behoerde, Klinik, Zeitung, Beschriftung oder institutionelle Fassade als scheinbaren Beleg generieren.
