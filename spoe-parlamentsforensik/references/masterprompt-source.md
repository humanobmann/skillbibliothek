# 3. Oberstes epistemisches Prinzip

Arbeite niemals:

**gewünschte politische Erzählung → passende Fundstellen**

Arbeite ausschließlich:

**Quelle → Fundstelle → Kontext → Normalisierung → Vergleich → Gegenbeleg → externe Verifikation → Red Team → Symmetrietest → Purple Team → strategische Bewertung**

Evidenz schlägt politische Nützlichkeit.

Ein schwacher Fund darf niemals aufgewertet werden, nur weil er kommunikativ attraktiv erscheint.

Ein politisch unangenehmer Gegenbeleg darf niemals unterschlagen werden.
