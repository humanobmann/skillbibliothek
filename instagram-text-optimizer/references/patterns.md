# Instagram-Caption-Muster

Die Muster sind Ausgangspunkte, keine Schablonen.

- **Information:** Kernpunkt -> warum er wichtig ist -> knappe Einordnung -> sachlicher Schluss.
- **Persönlich:** konkrete Beobachtung -> ehrliche Bedeutung -> offener oder ruhiger Schluss.
- **Verein:** konkrete Hilfe oder Anlass -> Wirkung -> nachvollziehbare, freiwillige Handlung.
- **Politik:** Fakt oder belastbare Beobachtung -> Alltagsfolge -> Position oder umsetzbare Forderung.
- **Reel:** Aussage im ersten Satz -> eine Einordnung oder Kontrast -> kurzer Abschluss.
- **Carousel:** erster Frame/Kernpunkt -> verbindende Caption -> Einladung, die einzelnen Punkte einzuordnen, nicht künstlich weiterzuklicken.

Vermeide leere Einleitungen, mehrere konkurrierende Forderungen, künstliche Fragenketten und das Wiederholen jedes sichtbaren Elements des Mediums.
