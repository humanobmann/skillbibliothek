# Style Rules

Apply these defaults unless the user provides a different style guide.

## General Prose

- Prefer clear, concrete language.
- Use active voice when responsibility matters.
- Keep paragraphs short.
- Use bullet lists only when they improve scanning.
- Avoid filler phrases and inflated wording.
- Explain necessary technical terms briefly.
- Keep labels consistent: do not alternate between different names for the same concept.

## Document Flow

- Start with why the document exists.
- Put conclusions or decisions before supporting detail when readers need quick orientation.
- Use transitions between major sections.
- Separate facts, assumptions, recommendations, and open questions.

## Editing Rules

- Preserve meaning unless asked to change it.
- Do not remove constraints silently.
- Do not turn uncertain content into certainty.
- Do not add citations or statistics unless provided or verified through an allowed source.
- When shortening, keep obligations, decisions, numbers, names, deadlines, and risks.

## Tone Defaults

- Professional but not stiff.
- Direct but not rude.
- Precise rather than decorative.
- Helpful and action-oriented.
