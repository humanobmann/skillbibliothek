# Facebook Rewrite Patterns

Use these as flexible structures, not rigid templates.

## Information post

Question or clear point -> explanation -> example -> meaning -> concise close

## Opinion post

Position -> reason -> evidence or example -> implication -> conclusion

## Clarification or fact-check post

Claim -> verified facts -> missing context -> assessment -> conclusion

## Political demand

Problem -> affected people -> proven cause or responsibility -> solution -> specific demand

## Personal post

Concrete experience -> personal reaction -> broader meaning -> reflection or invitation

## Mobilization post

Why now -> why it matters -> what exactly to do -> practical detail

## Reaction post

What happened -> what is decisive about it -> evidence or context -> own position -> conclusion

## Robust general pattern

Hook -> core message -> concrete problem -> clear explanation -> evidence -> human meaning -> position -> solution or consequence -> strong close

## Hook functions

Choose one function and make it specific:

- clear position
- relevant contradiction
- verified surprising fact
- concrete observation
- personal perspective
- useful question
- conflict or tension

Avoid empty throat-clearing and curiosity gaps that hide the actual subject.

## Relevance bridge

Translate the abstract topic into one of these:

- money
- time
- access
- security
- fairness
- everyday burden
- local consequence
- legal or practical right
- opportunity or risk

## Number translation

For every important number, ask whether the reader needs:

- time period
- affected population
- comparison baseline
- trend
- nominal versus real value
- practical consequence

## Rhetorical toolkit

Use selectively:

- rule of three
- contrast
- controlled repetition
- one rhetorical question
- antithesis
- escalation

Do not stack devices merely to make the post sound dramatic.

## Ending patterns

Conclusion:
"That is the point that matters here."

Demand:
"That is why the next step must be ..."

Reflection:
"The real question is therefore not only X, but Y."

Experience prompt:
"How does this show up in your everyday life?"

Information:
"The underlying source is linked below."

Adapt naturally to the user's language and voice. Do not copy these lines mechanically.

## Output modes

### Standard rewrite

1. One short sentence identifying the most important improvement, only if useful.
2. Publish-ready post.

### Maximum optimization

1. Score and top three weaknesses.
2. Publish-ready post.
3. Optional short note on factual uncertainty or source needs.

### Analysis only

1. Score.
2. Strengths.
3. Highest-impact weaknesses.
4. Specific revision instructions.

### Only the text

Return only the publish-ready post.
