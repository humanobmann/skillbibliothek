# New Work and Redesign

Use this playbook for a new surface, a greenfield experience, or an explicit replacement of the current visual world.

## 1. Establish product truth

Determine from the request and repository:

* Who is using the surface?
* What single outcome matters most?
* What information must be understood before the primary action?
* Which states are required: loading, empty, error, success, disabled, permission denied, offline, destructive confirmation?
* Which technical constraints are real: framework, component library, content model, browser support, native platform, localization, performance budget?

Do not invent product claims, user quotes, metrics, pricing, or factual content.

## 2. Choose the surface mode

### Persuade

Lead with a strong narrative and a clear decision path. Use expressive composition when it supports trust and action. Visual drama must not obscure the offer or primary CTA.

### Operate

Design for repeated use. Prefer stable structure, predictable controls, efficient density, visible state, keyboard support, and low cognitive overhead.

### Read

Prioritize structure, line length, typographic rhythm, navigable headings, and a calm reading environment. Decoration supports comprehension rather than competing with it.

### Experience

Let the work or media become the first-class visual object. Reduce navigation and interface chrome to what helps discovery and orientation.

## 3. Commit to one visual world

Pick a coherent set of decisions for:

* composition and grid
* typography personality and hierarchy
* color logic
* surface treatment and depth
* icon and illustration language
* image treatment
* motion behavior
* shape vocabulary

A good direction can be described in one sentence. If the sentence needs several unrelated aesthetic labels, the concept is probably unfocused.

## 4. Build hierarchy before decoration

Define, in order:

1. Primary content or task
2. Primary action
3. Secondary actions
4. Context and supporting information
5. Navigation and utilities
6. Decorative material

Use size, placement, whitespace, contrast, and grouping before adding borders, shadows, gradients, or containers.

## 5. Responsive composition

Design at least the smallest and largest meaningful viewport, then make intermediate behavior intentional. Change composition when necessary. Do not merely reduce font sizes and gaps.

For dense product UI, test overflow, long labels, data tables, filters, sidebars, modals, sticky regions, and touch targets.

## 6. Finish states

No production surface is complete with only the happy path. Include the states the interface realistically encounters. Preserve layout stability when content loads or changes.

## 7. Bounded finish pass

Inspect desktop and mobile together. Record all meaningful defects first, then fix them as one coherent batch. Confirm once after the batch. Stop unless the confirmation reveals a regression.
