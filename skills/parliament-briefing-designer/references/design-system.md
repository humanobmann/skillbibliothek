# Austrian Parliamentary Briefing Design System

## Visual position

Design for a serious parliamentary office or committee preparation context. The document must feel more polished than a standard government PDF, but less promotional than a campaign brochure.

The style should evoke Austria and Parliament through colour, spacing, typography, stone-like neutral backgrounds, and procedural clarity. Do not imitate an official Parliament document or use protected symbols unless the user provides authorised assets.

## Official anchors to respect

- Austria is constitutionally associated with red-white-red. Use this as a restrained state reference.
- The Austrian Federal Corporate Design describes common appearance, layout rules, typography, and image language for federal communication.
- The Austrian Parliament has Corporate Design Manual material. If exact brand assets are not provided, do not guess or recreate official branding.

## Palette

Use this practical palette unless the user provides a stricter one:

| Role | Name | Hex | Use |
|---|---:|---:|---|
| Primary state accent | Austrian Red | #C8102E | top rule, section marker, key highlight |
| Deep institutional red | Deep Red | #7A0019 | cover block, critical line, footer marker |
| Text | Graphite | #202124 | body text, headings |
| Secondary text | Slate | #5B6068 | metadata, captions |
| Page background | Warm White | #FAF8F4 | page background or cover field |
| Panel background | Stone | #EFE8DE | briefing cards and side panels |
| Soft panel | Light Grey | #F3F4F6 | facts, neutral tables |
| Rule line | Parliament Grey | #D7D2C8 | separators, table lines |
| Sparse accent | Brass | #B08A2E | very small emphasis only |

Do not use bright party-red as a dominant fill. Do not use saturated red backgrounds behind long text. Red should guide, not shout.

## Typography

Use professional sans serif typography. Prefer available system fonts rather than bundled font files.

Recommended order:

1. IBM Plex Sans if available.
2. Source Sans 3 if available.
3. DejaVu Sans if available.
4. Aptos or Arial.
5. Helvetica fallback.

Type scale for A4:

| Element | Size | Weight |
|---|---:|---|
| Cover label | 9 to 10 pt | uppercase, semibold |
| Main title | 24 to 32 pt | bold |
| Subtitle | 12 to 15 pt | regular |
| Section heading | 12 to 15 pt | bold |
| Body | 9.5 to 10.5 pt | regular |
| Card title | 8.5 to 9.5 pt | uppercase or semibold |
| Footnote/source | 7.5 to 8.5 pt | regular |

## Page architecture

A4 portrait. Use generous margins. Recommended margins:

- top: 18 mm
- bottom: 17 mm
- left: 18 mm
- right: 18 mm

Use one-column layout for high authority and readability. Use two-column fragments only for facts, metadata, objection pairs, or question lists.

## Page types

### Page 1

Purpose: establish authority and usability.

Elements:

1. Thin red-white-red state rule at top.
2. Small label: PARLAMENTARISCHES BRIEFING.
3. Title and subtitle.
4. Metadata panel with Fuer, Anlass, Stand, Status.
5. Kurzlage card.
6. Kernbotschaft or politische Hauptlinie.
7. Zentrale Fakten as 3 to 5 data cards.

### Middle pages

Purpose: explain judgement and prepare action.

Elements:

- Section title with red number or small red rule.
- Fact, Bewertung, Schlussfolgerung triad.
- Line to Take as a strong quotation-like callout.
- Gegenargumente table with generous padding.
- Parliamentary levers as numbered steps.

### Final page

Purpose: enable immediate parliamentary action.

Elements:

- Konkrete Fragen grouped by theme.
- Kernforderung in a red-left-rule box.
- Next step box.
- Source and evidence note.

## Components

### Metadata panel

Use light stone background, no heavy border. Label/value pairs. Keep values short.

### Kurzlage box

Warm stone background. Maximum 8 to 10 lines. No bullets if a paragraph reads better.

### Data cards

Use 2-column card grid. Each card has a short label, a large value or claim, and a one-line caveat.

### Line to Take

Use white box with left red rule. The text should be bold enough to survive skim reading. Avoid quotation marks unless quoting a real person.

### Gegenargumente table

Two columns: Einwand and Antwortlinie. Use light header background and enough padding. Avoid dense grid lines.

### Parliamentary levers

Use a numbered sequence with small red number tokens. Keep each step to one or two lines.

## Anti-patterns

Avoid:

- party flyer aesthetics
- huge red blocks behind long text
- fake official seals
- flags as decoration on every page
- dense academic paragraphs
- equal-width tables with long text squeezed into narrow cells
- unsourced claim boxes
- stock icons that make the document look generic
