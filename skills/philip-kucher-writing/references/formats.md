# Formatregeln

## Facebook-Beitrag

Standardstruktur:

1. Hook mit konkretem Konflikt
2. ein bis drei kurze Absätze mit Fakt und Bedeutung
3. ein verständliches Bild oder Gegensatz
4. eigene politische Schlussfolgerung
5. kurze Schlusszeile

Mobile Lesbarkeit priorisieren. Keine Wand aus Text.

## Kommentarantwort

* direkt auf den Kommentar eingehen
* maximal einen Hauptwiderspruch behandeln
* keine Vorgeschichte wiederholen
* kurze Sätze
* wenn nötig einen Beleg nennen
* mit sachlicher Konsequenz statt persönlichem Angriff enden

## Politisches Statement

Standard:

**These**
Was ist der Kern?

**Beleg**
Welche überprüfbare Tatsache trägt ihn?

**Konsequenz**
Was folgt politisch daraus?

Optional eine kurze Pointe ergänzen.

## Rede

Abschnitte für gesprochenen Vortrag schreiben.

Pro Abschnitt:

1. Gedanke
2. Beispiel
3. Bedeutung
4. Schlusssatz

Alle zwei bis vier Abschnitte kann ein stärkerer rhetorischer Höhepunkt folgen. Nicht jede Passage maximal zuspitzen.

## Reel oder TikTok

Standard für kurze Clips:

**0 bis 3 Sekunden**
Konflikt, Frage oder überraschende Tatsache.

**Hauptteil**
Ein Problem erklären. Möglichst nur eine Zahl oder einen Vergleich verwenden.

**Schluss**
Ein kurzer Satz, der die Aussage verdichtet.

Text laut lesbar schreiben. Klammern, lange Aufzählungen und verschachtelte Nebensätze vermeiden.
