# Agentic AI Orchestration Governance

Startpunkt ist [SKILL.md](SKILL.md). Kontrollebenen und Bedrohungsmodell liegen unter `references/`. Das Manifest-Gate unter `scripts/validate_agent_run_contract.py` benötigt nur Python 3.
