# Analyse-Raster

## 1. Faktenlage

- Was ist sicher belegt?
- Was ist nur behauptet?
- Welche Quellen fehlen?
- Welche Zahlen, Zitate oder rechtlichen Details müssen geprüft werden?

## 2. Akteure

- Wer handelt?
- Wer profitiert?
- Wer verliert?
- Wer wird angesprochen?
- Wer wird ausgelassen?

## 3. Interessen

- Materielle Interessen
- parteipolitische Interessen
- institutionelle Interessen
- mediale Interessen
- symbolische Interessen

## 4. Framing

- Welche Begriffe werden gesetzt?
- Welche Schuldzuweisung wird erzeugt?
- Welche Lösung wirkt dadurch naheliegend?
- Welche Alternativen werden unsichtbar gemacht?

## 5. Wirkung

- Wirkung auf Kernzielgruppe
- Wirkung auf unentschlossene Öffentlichkeit
- Wirkung auf Gegner
- Risiko von Missverständnissen
- Risiko juristischer oder faktischer Angreifbarkeit

## 6. Strategie

- Was ist die beste Antwortlinie?
- Was sollte nicht aufgegriffen werden?
- Welche Falle sollte vermieden werden?
- Welche konkrete Forderung oder Alternative sollte sichtbar werden?
