# Facebook Publication Strategy

## Grundsatz

Nicht moeglichst viele Bilder verwenden, sondern so viele wie fuer die Aussage notwendig sind. Keine unbelegten Algorithmusversprechen machen.

Facebook Ranking und Rasterdarstellung koennen sich aendern. Bei kritischen aktuellen Plattformregeln nach Moeglichkeit aktuelle Meta-Quellen oder nachvollziehbare technische Tests pruefen.

## Single

Fuer eine dominante Botschaft.

Ziel:

- 4:5
- bevorzugt 1080 x 1350
- maximale mobile Feedflaeche
- verbindliches internes Profil `feed_4x5`: 72 px links/rechts, 90 px oben, 110 px unten fuer kritischen Text bei 1080 x 1350

Diese Werte sind interne konservative Produktionsreserven und keine behauptete offizielle Meta Safe Zone.

## Pair

Fuer zwei natuerliche Gegenpole:

- Problem und Loesung
- Behauptung und Fakt
- vorher und nachher
- zwei Perspektiven

Zwei getrennte 1:1 Dateien, bevorzugt 1080 x 1080.

## Trio

Bevorzugter kurzer Mehrbildmodus:

1. Hook oder Hero
2. Erklaerung, Beleg oder Vertiefung
3. Schlussfolgerung oder Abschluss

Drei getrennte 1:1 Dateien.

## Quad

Fuer vier ungefaehr gleichwertige Aussagen oder Schritte:

1. Kernbotschaft
2. Fakt oder Erklaerung
3. weiterer Fakt oder Kontrast
4. Konsequenz oder Abschluss

Vier getrennte 1:1 Dateien.

## Gallery

Fuenf bis zehn Dateien nur wenn ausdruecklich gewuenscht oder inhaltlich begruendet.

Regeln:

- Bild 1 funktioniert alleine.
- Die ersten vier Bilder ergeben bereits einen sinnvollen Kern.
- Keine unverzichtbare Information ausschliesslich in Bild 5 bis 10.
- Spaetere Bilder vertiefen, belegen oder ergaenzen.

## 1:1 Crop Resilience

Bei 1080 x 1080 kritische Inhalte innerhalb des zentrierten 900 x 900 px Bereichs halten. Das entspricht 90 px Innenrand auf allen Seiten. Fuer Hero-Elemente zusaetzlich mindestens 8 % optische Reserve und fuer zentrale Motive mindestens 12 % Crop-Reserve vorsehen.

Diese Zone ist eine interne robuste Designregel, keine offizielle Meta Safe Zone.

## Tool Only

Jede Facebook-Datei separat mit `image_gen` erzeugen oder editieren.

Nicht erlaubt:

- programmatisches Cropping
- programmatisches Resizing
- externe Textueberlagerung
- 2x2 Raster als einzelne Datei
- Kontaktbogen als Endprodukt
