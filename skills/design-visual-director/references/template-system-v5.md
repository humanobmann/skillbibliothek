# Native Canva Master Template System 5.0

## Ten families, one registry, separate brands

| Family | Formats | Purpose |
| --- | --- | --- |
| editorial | 1080x1350 | photographic or symbolic political/editorial posts |
| facts | 1080x1350 | verified number, unit, reporting period and source |
| quotes | 1080x1350, 1080x1080 | exact attributed quotations |
| events | 1080x1350, 1080x1920, landscape | place, date, attendance, RSVP |
| story_reel | 1080x1920 | Story, reel cover and independently checked safe areas |
| explainer | carousel | editable sourced facts and native charts |
| headers | landscape | Facebook cover, newsletter and campaign header |
| print | A1, A3, A4 | printer specification, trim/bleed and effective ppi |
| newspaper | multi-page | community newspaper, issue management and print review |
| author_editorial | as commissioned | private book covers, portraits, essays |

These are families, not ten promises of existing Canva Brand Templates. Each family is created only for brands that need it. New designs are actual editable Canva designs, not saved HTML or a single screenshot.

## Registry schema and governance

Store the approved internal registry in an authorized private location, not in the public Git repository. One record per template:
- project_scope, canva_account, brand_namespace, brand_kit_id;
- master_design_id, template_id, family, supported_format, source_design_ids;
- fonts, native text element IDs, original logo asset IDs, safe_region_version;
- autofill dataset names/types, frame asset IDs and version;
- owner, rights_state, status, QA evidence, approval reference and real Canva edit/view links.

Historical source designs remain intact and unchanged. Duplicate V6/V7/V8 outputs must not be mass-deleted. Old official party designs in the Peter account must not be carried into SPÖ by an unsupported cross-account copy.

## Field conventions

Use verified native Canva fields whenever the source design supports Autofill:
headline, subheadline, body, quote, attribution, stat_value, stat_label, reporting_period, date, time, location, cta, source, source_url, version and image_asset_id. Field names above are conventions, not claims about existing Canva schemas.

Read get_design_dataset / get_brand_template_dataset first. Empty output means fields must be deliberately labeled in an approved working copy before autofill can be used. Do not label a generated image and pretend separate text elements were created.

## Pilot and rollout

First prove a single approved feed master in the correct account, then one story, one Section VII event, one Peter personal editorial and one Menschlichkeit Österreich graphic. Require the five real designs, edit links, native text and logo checks, format-specific safe-region proofs and human visual acceptance. Only then enable recurring batch processing. Record measured production time before asserting speed improvement.
