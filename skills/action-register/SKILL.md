# Action Register

## Auftrag

Verwandle unstrukturiertes Material in ein prüfbares Ausführungsregister.

## Workflow

1. Quelle, Zeitraum, Beteiligte und Projektkontext bestimmen.
2. Explizite Entscheidungen von Vorschlägen, Vermutungen und offenen Fragen trennen.
3. Jede Aufgabe normalisieren: Aktion, erwartetes Ergebnis, Owner, Fälligkeit, Abhängigkeit, Status, Evidenz und Abnahmekriterium.
4. Risiken, Blocker, Genehmigungen und Konflikte separat erfassen.
5. Dubletten zusammenführen, widersprüchliche Angaben sichtbar machen.
6. Fehlende Owner, Fristen oder Zuständigkeiten mit `OFFEN` markieren statt sie zu erfinden.
7. Auf Wunsch eine kurze Follow-up-Nachricht aus dem Register ableiten.

## Ausgabe

- Kurzüberblick
- Entscheidungslog
- Action Register
- Risiken/Blocker
- offene Fragen
- Follow-up, nur wenn verlangt

Jeder Eintrag muss auf die Quelle oder den belegten Kontext zurückführbar bleiben.
