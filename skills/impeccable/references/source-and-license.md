# Source, Adaptation, and License

This skill is a ChatGPT-oriented adaptation of the open source project **Impeccable** by Paul Bakaus.

Upstream repository:
https://github.com/pbakaus/impeccable

Upstream project description at adaptation time: design guidance for AI coding agents with one main skill, 23 commands, live browser iteration, and a deterministic detector suite.

Observed upstream skill version at adaptation time: 4.0.4.

License: Apache License 2.0. A copy is included as `LICENSE.txt`.

This package is not a verbatim mirror of the upstream CLI distribution. It preserves the command vocabulary, design principles, routing concepts, and quality goals in a portable ChatGPT skill, while replacing the upstream Node-based runtime and detector suite with concise model instructions and a small dependency-free Python lint helper.

Third-party notice from upstream: the upstream iOS and Android reference material includes distilled ideas from `ehmo/platform-design-skills`, originally MIT licensed. This adaptation uses general platform guidance rather than copying those upstream reference files.
