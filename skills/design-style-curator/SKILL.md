# Design Style Curator 1.0

Provides a selective inspiration vocabulary grounded in `bergside/awesome-design-skills` (67 profiles, MIT), NOT 67 additional executors or font licenses. The repository primarily describes web UI design systems; reinterpret only suitable composition, type rhythm, materiality and hierarchy for graphic/print/social work. Do not pretend upstream skill imports or CLI commands were executed.

## Workflow
1. Identify purpose, format, protected references, audience, accessibility and existing style authority.
2. Search the local `references/bergside-catalog.json` for fitting profile slugs by intent. If GitHub tools are available and fresh detail is needed, read upstream `skills/<slug>/SKILL.md` and `DESIGN.md` only after source check. Do not execute downloaded scripts, installer or `npx typeui.sh pull` without explicit separate authorization and a trustworthy environment.
3. Shortlist at most 3 different profiles; lead with one user-driven concept; explain intended visual language rather than copy upstream colors or fonts. Fonts listed upstream are examples, not automatically installed or licensed on the host.
4. Run style conflict checks: user visual reference > existing approved organizational design system > actual brief > curated inspiration. Prevent template copying of people, logos, claims or identity. No style may override text locks or actual print constraints.
5. Make a concrete style brief: type character, grid, contrast, motif logic, materiality, negative space, image role, anti-patterns and optional tokens. Record source reference and what was adapted.
6. Hand style proposal to `design-visual-director` for real production; the curator alone does not claim to produce an image.

## Recommended editorial family
Editorial = refined grids and serif-aware reading. Minimal = space and constraint. Refined = controlled restraint. Brutalism = deliberate visual tension. Riso = analogue two-color printing cue only when relevant. Storytelling = sequential emotional arc. Geometric = abstract shape logic. Contemporary = modern structure. Use actual user brand palettes over upstream token values. UI-specific interface patterns like Shadcn, Material, Bento or Neumorphism are not default poster designs.
