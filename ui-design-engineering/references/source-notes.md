# Source notes

Primary source: `https://github.com/ibelick/ui-skills`

Upstream project: UI Skills, described by its maintainers as skills for design engineers.

Upstream skill families reviewed for this adaptation:

- `baseline-ui`
- `create-design-md`
- `fixing-accessibility`
- `fixing-metadata`
- `fixing-motion-performance`
- `improve-ui`
- `ui-skills-root`

The upstream repository is MIT licensed. This package consolidates the public rule sets into a single ChatGPT-oriented router skill with modular references and normalized ChatGPT skill metadata. Wording has been condensed and adapted rather than preserving the upstream files verbatim.
